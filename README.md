# GHUKASI — Official Artist Website

Bilingual official website for electronic music project **GHUKASI / Denis Ghukasyan / Денис Гукасян**.

The public site is designed for GitHub Pages. Configure the repository under Settings → Pages → Deploy from a branch → `main` → `/docs`.

Once GitHub Pages is enabled, the site URL will be `https://danceruuu.github.io/my-project/`.

Includes a browsable 105-track Apple Music discography, verified artist profile links and Google-friendly structured data.
